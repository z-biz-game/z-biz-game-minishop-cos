⚓孤舰MINISHIP

玩法：怎么摆才算对

目标：把这一关舰队清单里的每条船都摆进海图，让每一行的、每一列的数字同时兑现。数字全对上、且没有两条船挨着，这一关就成了。

线索怎么读：海图左边的数字是这一行要被船占住的格子数，上边的数字是这一列要占住的格数。写着 - 的行/列是自由行自由列（FREE = -1，js/core/model.js:19），它不约束占格数。

怎么操作：从右边的架子上把一条船拖进海图，它会横放；按「旋转」改成竖放，再拖到位。在空白海图上单击一下是标记水（UNKNOWN / SHIP / WATER 三态，js/core/model.js:7）。撤销只退你动过的一步。

判对判错由谁说：js/core/check.js 是独立检查器——它不碰位掩码、不碰行计划、不 import 计数器与求解器，只用嵌套循环和一张朴素占格表把上面那句话重新推一遍。它按顺序查六件事，任何一件不对就报一句人话：

  1. 题面自洽：Σ行线索 = Σ列线索 = Σ船长。
  2. 每条船都在图内。
  3. 两条船不共格。
  4. 两条船不挨着——边和角都算（Akaji 规则）。
  5. 每条受约束的行/列恰好占那么多个格。
  6. 放下船长度的多重集正好是舰队清单。

第 1 条那条恒等式是地基：数同一批格子的三种方法必须互相同意，否则这道题根本不描述任何一支舰队。

这一关的数字从哪来

解数由 js/core/count.js 逐行穷举证出：数字是 1 就意味着它走完了每一种可能，只找到一种摆法。船与船不得相邻，斜角也算相邻——这条规则写进了求解、校验和绘制三处，改了它解数就会变。

推理深度由 js/core/logic.js 量出：只用局部推理能走完就是 0 层；需要假设一处才走得下去是 1 层，以此类推。两个计数分开放：操作数算你动过的每一步（包括点水），放置步数只算落下的船，它的下限就是船数。

关卡来自 node tools/bake.mjs：构建期随机摆舰队 → 读出行列线索 → 验唯一 → 跑逻辑求解器拿深度，只有全部复现的才写进 js/data/puzzles.js。浏览器本身不做生成。
